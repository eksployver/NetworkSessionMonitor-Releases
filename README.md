\# Network Session Monitor

\*\*Network Session Monitor\*\* — это portable Windows-приложение для мониторинга качества интернет-соединения во время игр.

Приложение помогает отслеживать:

\- ping;

\- packet loss;

\- jitter;

\- timeouts;

\- spikes;

\- нестабильность маршрута до игровых серверов;

\- проблемы локальной сети, провайдера или конкретного сервера.

Network Session Monitor не вмешивается в игры, не читает память процессов, не обходит античиты и не является VPN.

Возможности
мониторинг ping в реальном времени;
расчёт packet loss;
расчёт jitter;
график ping;
профили мониторинга для игр;
автоопределение игровых TCP-хостов;
история сессий;
Diagnostic Report;
экспорт CSV/TXT;
русский и английский интерфейс.
Где хранятся данные
%LOCALAPPDATA%\NetworkSessionMonitor
Ограничения

Приложение:

не является VPN;
не снижает ping само по себе;
не оптимизирует маршруты;
не читает память игр;
не внедряется в процессы игр;
не обходит античиты;
только измеряет и анализирует качество соединения.
