\# Network Session Monitor



\*\*Network Session Monitor\*\* — это portable Windows-приложение для мониторинга качества интернет-соединения во время игр.



Приложение помогает отслеживать:



\- ping;

\- packet loss;

\- jitter;

\- timeouts;

\- spikes;

\- нестабильность маршрута до игровых серверов;

\- проблемы локальной сети, провайдера или конкретного сервера.



Network Session Monitor не вмешивается в игры, не читает память процессов, не обходит античиты и не является VPN.

Как пользоваться

Запусти NetworkSessionMonitor.App.exe.

Открой Settings / Настройки.

Выбери профиль, например General / Общий, CS2, PUBG, Arc Raiders или Custom / Пользовательский.

Проверь список хостов.

Нажми Start Monitoring / Начать мониторинг.

После теста нажми Stop / Остановить.

Открой History / История, чтобы посмотреть сохранённую сессию.

Используй Export CSV или Export Report, если нужно сохранить данные.

Автоопределение игровых хостов



В настройках есть функция:



Auto-detect game hosts / Автоопределить хосты игры



Она позволяет выбрать процесс игры и найти удалённые TCP-адреса, к которым он подключается.



Важно:



игры могут подключаться не только к игровым серверам, но и к серверам авторизации, голосового чата, телеметрии и CDN;

UDP detection в текущей версии может быть ограничен;

найденный IP не всегда является именно сервером матча;

лучше запускать определение уже во время матча.

Динамические игровые хосты



Автоматически найденные игровые IP добавляются как dynamic hosts.



Если dynamic-host становится неактивным, приложение удаляет его через заданное время.



По умолчанию:



2 минуты



Это значение можно изменить в настройках:



Remove inactive game hosts after, min

Удалять неактивные игровые хосты через, мин



Router, Cloudflare DNS, Google DNS, Quad9 DNS и ручные хосты автоматически не удаляются.



Где хранятся данные



Приложение хранит настройки и историю не рядом с .exe, а в профиле пользователя Windows:



%LOCALAPPDATA%\\NetworkSessionMonitor



Файл настроек:



%LOCALAPPDATA%\\NetworkSessionMonitor\\appsettings.local.json



База истории:



%LOCALAPPDATA%\\NetworkSessionMonitor\\network\_sessions.sqlite



Если удалить эту папку, приложение создаст настройки заново при следующем запуске.



Как понять результаты



Если проблемы видны на Router, вероятна проблема дома: Wi-Fi, кабель, роутер или сетевой адаптер.



Если Router стабилен, но Cloudflare DNS и Google DNS нестабильны, вероятна проблема у провайдера или на внешнем интернет-канале.



Если Router и DNS стабильны, но плохой конкретный game/custom host, вероятна проблема маршрута до сервера, региона сервера или самого игрового сервера.



Если сеть стабильна, но игра всё равно лагает, причина может быть не в сети: FPS, CPU/GPU, настройки игры, сервер игры или сама игра.



Ограничения



Network Session Monitor:



не является VPN;

не снижает ping само по себе;

не оптимизирует маршруты;

не читает память игр;

не внедряется в процессы игр;

не обходит античиты;

не гарантирует определение UDP-only игровых серверов;

только измеряет и анализирует качество соединения.
